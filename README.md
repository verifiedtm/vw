# vw

A video workbench for people and agents making edits through code. Describe a
sequence in plain-text project files, preview it, and render a finished video.
Original footage stays intact, and edits are easy to revise and reuse.

Use it to assemble clips, match cuts to music, build layered compositions, and
keep a searchable library of gestures and camera moves for future projects.

See [Using vw](USAGE.md) for setup, examples, and the editing workflow.
For work on the codebase, see [Development](AGENTS.md).
